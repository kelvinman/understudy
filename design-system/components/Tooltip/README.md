# Tooltip

One shared `us-tip` the page moves to whatever is hovered or focused: a word or two about an icon, or the full text of a value that was cut.

- A bold first line (`us-tip-title`) says what the thing is ("Careers page"); an optional grey second line (`us-tip-detail`) gives the detail ("jobs.ashbyhq.com").
- Show it on hover and on keyboard focus, never only on hover. Place it above the element, centred, kept 8px inside the window; below when there is no room above. Hide it on scroll.
- Never put something only in a tooltip that the reader needs to act. It explains; it does not hold the content.
