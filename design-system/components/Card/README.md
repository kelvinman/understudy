# Card

Two containers, both used sparingly. `us-card` is a `border-subtle` outline at `radius-lg`, for one object that must stand apart, such as a key number at the top of a report. `us-quote` is a `bg-muted` block, like a message bubble, for quoted or user-written text.

- Most content needs neither: sections on the open page, split by `us-divider` or a full-width `us-rule`.
- Never nest cards. Never add a shadow; the app uses none on content.
