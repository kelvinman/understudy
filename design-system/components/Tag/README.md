# Tag

A small label for a category or state.

- Default `us-tag` is a muted fill in `text-secondary`. `us-tag-outline` for a tag beside other filled things.
- `us-tag-success` and `us-tag-danger` for verdicts, `us-tag-warning` (amber) for in motion. Always say the state in words; the color only backs it up.
- Text 12px weight 500, corners `radius-sm`. Tags are not buttons: never make one clickable.
