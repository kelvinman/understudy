# Run of show

A page for anything run in time order: a demo, a talk, a workshop, a walkthrough on a call. A timeline strip at the top, then one beat per section, each with its time range and title, a drawn screen on the left and the notes on the right.

- Timeline: `<nav class="us-timeline">` of links, one per beat, `style="--us-span:90"` for its length (seconds, or any unit, as long as all segments use the same one), each named in a word or two with the full name in `title`. Every segment is the same grey. The strip sticks to the top as the page scrolls; set `aria-current="true"` on the segment of the beat in view, which turns it dark. A beat done live says so with a `us-tag` in its heading, not in the strip.
- Beat: `<section class="us-beat" id="…">` with `us-beat-head` (`us-beat-time` "1:30 to 3:00", then `h2.us-beat-title`, then a tag if needed), a `us-screen`, then `us-beat-notes`. Notes are short labelled parts, each a `us-beat-label` above a `p`: On screen, Do, Say. What is said goes in `us-beat-say`, in the serif.
- Screen: `us-screen` with `us-screen-bar` (`us-screen-dots` of three empty spans, `us-screen-title`), then any content, drawn with the page's own classes rather than a screenshot. Add `is-page` when it shows a website or app: it takes a browser's 16:10 proportions and clips what does not fit, so it never reads as a short card. Add `is-slide` for a deck, drawn as a presentation tool: a `us-deck` with a `us-deck-rail` of `us-deck-thumb`s (`is-current` on the one showing) and a `us-deck-stage` holding the `us-slide` (`us-slide-title`, `us-slide-text`, `us-slide-num`) at 16:9. For a terminal, `us-screen-term`, one text line per line: `us-term-cmd` for what was typed, `us-term-dim` for working lines, `us-term-ok` for the line that says it worked, `us-term-link`, and `us-term-caret` at the end.
- Other kinds: a phone is `us-phone` around a `us-phone-screen`, in place of a `us-screen`. A video call is `us-screen is-call` with a `us-call`: the person speaking in `us-call-tile is-main`, the others in `us-call-side`, each tile a `us-call-face` and `us-call-name`, and a `us-call-bar` of `us-call-btn` (`is-end` to leave). A file is a `us-screen` with a `us-ide`: a `us-ide-tree` of `us-ide-item`s (an icon then a name; `is-nested`, `is-open`) beside a `us-editor` of numbered `us-editor-line`s (`is-add`, `is-del`, `is-gap`). The tree is what tells it apart from a terminal. A beat that is only talking takes `is-talk` and no screen.
- Up to 1000px wide. Under 860px the notes go under the screen. Close the page with prep and fallback lists.
