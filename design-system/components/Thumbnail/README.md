# Row thumbnail and text button

Two small pieces for rows in a table or list.

- `us-thumb` is an 88 by 56 picture beside a row's text, inside `us-with-thumb`. It is a button that opens what it shows, such as the journal the picture came from. When there is no picture, `is-empty` keeps a grey tile with an icon for the row's kind, so rows still line up.
- `us-text-btn` is a button that reads as the text it sits in, such as a row's title that opens its record in the same page: underlined in a light line that darkens on hover. Use a link instead when it goes to another page.
