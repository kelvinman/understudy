# Fields

Facts about one record as a label column and a value, closed by hairlines, inside a Split's detail or a short page.

- Markup: `<dl class="us-fields"><div><dt>Why</dt><dd>…</dd></div>…</dl>`.
- Labels are short nouns in `text-secondary`; values are body text and may hold links or a short list.
- Under 520px of container width the label stacks above its value.
