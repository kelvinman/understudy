# Panel

The Workspace cards preset's container: a `bg` panel on the `bg-canvas`, `border-subtle` outline, `radius-xl` corners, 32px padding, beside the nav in `us-workspace-main`.

- Open each panel with `us-panel-head`: a `us-display` title in the serif on the left, one bordered action on the right.
- Inside, split sections with `us-section-head` and full-width Tables.
- Panels stack with a 12px gap. Never nest a panel or put a card inside one. Only Workspace pages use panels.
